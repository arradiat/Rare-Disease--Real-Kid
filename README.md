# Rare Disease, Real Kid

An end-to-end rare-disease variant prioritization pipeline for Track 1 of the 2026 MVA hackathon. The project combines genome processing and clinical filtering with a learned Singular Bayesian Neural Network (SBNN Toure \& Stephens, 2026) ranker. The final prediction identifies the accepted compound-heterozygous `BUB1B` pair at rank 1.

**Team:** Mame Diarra Toure and Bonaventure Dossou

### Exact code path that generated the CSV

The public entry point is [`generate_track1_submission.py`](generate_track1_submission.py). This command regenerates the canonical file from the committed audited SBNN prediction:

```bash
python generate_track1_submission.py
```

Passing `--ranking-zip` first reruns the fitted models on the actual compact child candidate table. The full code path has four explicit stages:

1. [`generate_track1_submission.py`](generate_track1_submission.py) is the command-line entry point and orchestrates inference and export.
2. [`models/wide_rank50_sbnn.py`](models/wide_rank50_sbnn.py) defines and trains the selected architecture and fixes its rank, KL weight, posterior scale, prior scale, and number of posterior draws.
3. [`verify_temporal_models_track1.py`](verify_temporal_models_track1.py) loads the fitted checkpoint, runs the selected SBNN on both alleles of every child candidate pair, computes `sqrt(p1 * p2) * phenotype_score`, and writes `results/track1_temporal_transfer_20260906/strict_wide_rank50_sbnn.csv`.
4. [`export_track1_sbnn_submission.py`](export_track1_sbnn_submission.py) selects that exact model output, validates its schema and local score, and writes `submission/model1_bonamame_wide-rank50-sbnn.csv` plus its manifest.

The canonical command is `python generate_track1_submission.py`. Its probabilities come from `models/wide_rank50_sbnn.py` through `verify_temporal_models_track1.py`. No deterministic score is copied into the SBNN submission.

## What the project does

The challenge asks for the pair of genetic variants that best explains the child's disease. Millions of raw variants cannot be treated as equally plausible. The pipeline first establishes a biologically valid candidate set, then applies learned probabilistic ranking.

```text
FASTQ and supplied VCF
        |
alignment, quality control, normalization and annotation
        |
rare, damaging, inheritance-compatible variants
        |
gene-level compound-heterozygous candidate pairs
        |
wide rank-50 SBNN allele probabilities + HPO phenotype similarity
        |
ranked Track 1 candidate pairs
        |
submission/model1_bonamame_wide-rank50-sbnn.csv
```

The upstream genome workflow was developed by Bonaventure Dossou and is available in [bonaventuredossou/hf_rare_disease](https://github.com/bonaventuredossou/hf_rare_disease). It performs read processing, variant quality control, annotation, rarity and consequence filtering, inheritance reasoning, phasing, phenotype matching, and candidate-pair construction. Its exported candidate tables and phenotype scores are inputs to the models in this repository.

Mame Diarra Toure developed the Bayesian modeling and evaluation extension: a shared feature contract, linear Bayesian baseline, end-to-end pair SBNN, dense Bayes-by-Backprop models, the wide rank-50 SBNN, deep-ensemble comparisons, hyperparameter sweeps, temporal ClinVar evaluation, Phenopacket/HPO patient-level tests, uncertainty analysis, figures, and exact Track 1 verification.

The two parts form one pipeline. Candidate generation protects biological validity; the SBNN learns how pathogenic evidence should be combined and supplies a posterior predictive distribution rather than a single fixed score.

## Selected model

The final submission uses the `wide_rank50_sbnn` model:

| Component | Value |
|---|---|
| Training labels | ClinVar 2023 pathogenic versus benign variants |
| Input dimension | 50 allele-level features |
| Hidden layers | 200, 100 |
| Low-rank configuration | 50, 50, 1 |
| KL weight | 0.01 |
| Posterior scale multiplier | 0.1 |
| Prior scale | 0.3 |
| Seed | 20260905 |
| Posterior draws for Track 1 | 128 |
| Pair score | `sqrt(p1 * p2) * phenotype_score` |

The challenge answer, submitted rank, previous pair score, ClinVar significance, CADD, REVEL, and SpliceAI were excluded from the Track 1 transfer adapter to avoid answer leakage. Candidate construction and phenotype similarity still come from the upstream genome pipeline.

The wide rank-50 SBNN was selected because it produced the strongest temporal variant-ranking result among the learned models tested. It was not the best unseen-gene detector; the five-network ensemble had the stronger OOD AUROC. The distinction between ranking quality and OOD detection is important and is preserved throughout the report.

The SBNN is also the most scalable Bayesian architecture tested. A dense Bayes-by-Backprop layer requires a posterior mean and scale for every weight, so its variational parameter count grows with the full weight matrix. The SBNN stores Bayesian low-rank factors instead. For a layer with input width `d_in`, output width `d_out`, and rank `r`, the weight-posterior storage grows as `O(r * (d_in + d_out))` rather than `O(d_in * d_out)`. The post-submission 54-200-100-1 rank-50 model contains 56,204 variational scalars, versus 62,402 for a width-matched dense BBB and 156,005 stored weights across a width-matched five-network ensemble. That is a 9.9% reduction relative to dense BBB and a 64.0% reduction relative to the ensemble. The dense-BBB saving is modest because rank 50 is not very small for these widths; it grows for wider layers when rank remains controlled. Monte Carlo prediction still requires repeated forward passes.

REVEL and AlphaMissense output deterministic pathogenicity scores. Their standard outputs do not include posterior draws, predictive standard deviation, or epistemic mutual information. The SBNN produces all of these from one fitted posterior. This is a built-in uncertainty mechanism, not proof that its uncertainty is automatically calibrated: calibration, OOD detection, and selective referral must still be evaluated. Because the augmented SBNN consumes REVEL and AlphaMissense scores, its 56,204-scalar count describes the added Bayesian ranker, not the storage or compute of the complete upstream annotation stack.

## Results beyond the child

Perfect performance on one solved child does not establish generalization. The models were therefore compared on temporal ClinVar variants and post-2023 solved Phenopacket cases.

| Method | Main role | External result |
|---|---|---:|
| Gradient boosting | Deterministic tabular baseline | Top-1 81.50%, PR-AUC 0.9674 |
| Five-network ensemble | Uncertainty and OOD comparison | OOD AUROC 0.7485, NLL 0.1245 |
| Original small SBNN | Initial low-rank Bayesian model | Top-1 82.10%, OOD AUROC 0.6020 |
| Temporal consensus | Combination of tree, ensemble and SBNN | Top-1 83.65%, PR-AUC 0.9731 |
| Dense BBB | Independent posterior per parameter | Top-1 83.00%, PR-AUC 0.9729, OOD AUROC 0.6665 |
| Wide rank-50 SBNN | Selected Track 1 learned ranker | Top-1 84.35%, PR-AUC 0.9736, F-max 0.9235, OOD AUROC 0.6284 |
| Wide dense BBB | Width-matched Bayesian comparison | Top-1 81.35%, OOD AUROC 0.6567 |

On 719 post-2023 solved Phenopacket cases, the HPO-conditioned dense BBB reached 58.9% +/- 1.0% top-1 across repeated candidate draws. On the 64 two-variant cases, the wide dense BBB reached 68.1% top-1. These experiments use constructed ten-candidate sets and test ranking, not complete genome-wide diagnostic sensitivity.

### Generalization beyond the challenge child

After obtaining the maximum Track 1 score, we tested whether the learned
ranking methods could transfer to independent causal variants in realistic
genome-scale candidate backgrounds. The complete experiment is documented in
[`docs/POST_SUBMISSION_GENERALIZATION_2026-09-08.md`](docs/POST_SUBMISSION_GENERALIZATION_2026-09-08.md).

The eight saved models were first evaluated without retraining on all 275,739
VarPB v3 spike-in trials. The best of them, the original small SBNN, had median
causal rank 522 and Top-100 0.20%; this showed that compact shortlist performance
did not transfer to whole-background ranking. REVEL and AlphaMissense established
stronger external targets.

A new SBNN was then trained only on the verified 26 December 2023 ClinVar
snapshot. It adds REVEL and AlphaMissense values plus explicit missingness flags,
uses a Bayesian pairwise ranking loss, and was selected by a complete 24-cell
rank/KL/posterior-scale/prior-scale screen on a gene-disjoint validation split.
VarPB was not used for training or selection.

| Locked VarPB result | Median rank | Top-1 | Top-20 | Top-100 | MRR |
|---|---:|---:|---:|---:|---:|
| Predictor-augmented pairwise SBNN | 14 | 7.26% | 65.70% | **86.63%** | 0.1596 |
| REVEL | **8.5** | **12.48%** | **65.90%** | 84.82% | **0.2516** |
| AlphaMissense | 29 | 8.84% | 44.24% | 69.72% | 0.1632 |

The new SBNN is competitive for shortlist recall: it essentially matches REVEL
at Top-20 and exceeds it at Top-100, while remaining weaker at Top-1 and MRR.
Because REVEL and AlphaMissense are inputs, this is a learned evidence-integration
claim, not a claim that the SBNN independently replaces either predictor.

The same frozen augmented checkpoint was then evaluated on the Track 1
compound-heterozygous candidates. It retained the accepted BUB1B pair at rank 1
in both the strict and broad sets. The strict CSV achieved the local
official-equivalent maximum of 100 Rank Points and F-max 1.000; this augmented
result has not been submitted to the live evaluator. The exact command is:

```bash
python evaluate_augmented_sbnn_track1.py \
  --ranking-zip ../ranking.zip \
  --checkpoint results/varpb_augmentation_20260908/augmented_sbnn.pkl \
  --revel-database data/open/opencravat_modules/annotators/revel/data/revel.sqlite \
  --alphamissense-database data/open/opencravat_modules/annotators/alphamissense/data/alphamissense.sqlite \
  --output-dir results/track1_augmented_sbnn_20260908
```

Detailed interpretation, figures, limitations, and citations are in the [methods report](output/pdf/bonamame_track1_report.pdf). A shorter model summary is available in [`docs/MODEL_AND_RESULTS.md`](docs/MODEL_AND_RESULTS.md).

## Reproduce the SBNN submission

The repository includes the fitted temporal-model checkpoint and the compact prediction artifacts. It does not include the 85 GB patient bundle.

To rebuild the SBNN predictions from Bonaventure's compact `ranking.zip` export:

```bash
python -m pip install -r requirements-report.txt

python generate_track1_submission.py \
  --ranking-zip /path/to/ranking.zip \
  --checkpoint results/track1_temporal_transfer_20260906/trained_models.pkl

python audit_submission.py submission/model1_bonamame_wide-rank50-sbnn.csv
python verify_track1_exact_scores.py
```

`generate_track1_submission.py` calls the guarded exporter. The exporter refuses to publish if the source run audit is missing, the model output does not match the required schema, or the selected model fails the local score check. It writes both the CSV and a manifest containing hashes, model settings, provenance, and score results.

For a clean training run rather than checkpoint inference, pass `--historical data/open/clinvar_temporal/clinvar_20231226.vcf.gz` when the checkpoint does not exist.

Dataset sources, checksums, CPU environment, and the complete build procedure are documented in [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md).

## Data policy

The private SageBio challenge files are not committed. The approximately 85 GB bundle contains four paired-end FASTQ lanes, a supplied whole-genome VCF, and a clinical phenotype document. It was processed on cluster storage, not on the local Mac.

The external data are public and versioned:

- ClinVar GRCh38 archives from [NCBI](https://ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh38/)
- Phenopacket Store 0.1.27 from the [Monarch Initiative](https://github.com/monarch-initiative/phenopacket-store/releases/tag/0.1.27)
- HPO release files from the [Human Phenotype Ontology repository](https://github.com/obophenotype/human-phenotype-ontology/releases)

No patient FASTQ or full VCF is present in this repository. See [`data/README.md`](data/README.md) for the expected local layout.

## Citation and authorship

The project is joint work by Mame Diarra Toure and Bonaventure Dossou. The public repository and Bonaventure's upstream feature pipeline are both cited in the LaTeX report. Citation metadata for this repository is provided in [`CITATION.cff`](CITATION.cff), and the bibliography audit is in [`report/CITATION_AUDIT.md`](report/CITATION_AUDIT.md).

Scientific limitations remain explicit: the current experiments do not establish direct trans phase for the two `BUB1B` alleles, functional pathogenicity of p.Asn1002Lys, calibrated clinical risk across hospitals, or full-genome diagnostic sensitivity on a multi-patient cohort.

The generalization protocol, fixed failure criteria, executed public VarPB benchmark, and post-submission chronology are documented in [`docs/GENERALIZATION_BENCHMARK.md`](docs/GENERALIZATION_BENCHMARK.md) and [`docs/POST_SUBMISSION_GENERALIZATION_2026-09-08.md`](docs/POST_SUBMISSION_GENERALIZATION_2026-09-08.md). These experiments strengthen the evidence for transferable candidate ranking, but they still do not constitute a clinical sensitivity estimate from native HPO, pedigree, and full VCF data across an independent hospital cohort.
